# Unit Tests — Single-Interaction UI Behaviors (Branch: claude-capstone-with-artifacts)

Scope: `src/App.jsx`, `src/App.css`. Covers single-interaction UI behaviors (one click/hover/focus
at a time) for the color-coded button categories (SCRUM-6) and pre-existing basic interactions.
Does not cover multi-step calculation flows — see `Artifacts/integration-tests_231120260146.md`
for those.

Each test ID, Steps, and Expected Result below is executed verbatim via Playwright MCP against
`http://localhost:5173` (Vite dev server, `npm run dev`).

---

**Steps:**
1. Navigate to `http://localhost:5173`.
2. Click the button labeled "7".
3. Take a snapshot.

**Expected Result:** The `.display` element shows `7`.

## UT-9 — Hover reduces opacity to 0.8 (per category, AC-5)
**Steps:**
1. Navigate to `http://localhost:5173` (fresh load).
2. Hover the mouse over the "5" (`.number`) button.
3. Read the computed `opacity` of the hovered button.

**Expected Result:** Computed `opacity` is `0.8` while hovered (per the shared `button:hover { opacity: 0.8; }` rule in `src/App.css`), and reverts to `1` (unset) when the mouse moves away. Confirmed for one representative button per category (number); the hover rule is shared/unscoped so all four categories use the same rule.

## UT-10 — Focus-visible outline appears and isn't clipped (R4)
**Steps:**
1. Navigate to `http://localhost:5173` (fresh load).
2. Press `Tab` repeatedly to move keyboard focus through the button grid (C → ÷ → × → 7 → 8 → 9 → − → 4 → 5 → 6 → + → 1 → 2 → 3 → = → 0 → .).
3. At each focused button, read the computed `outline`/`outline-offset` and confirm the 2px white outline is fully visible (not clipped by the `.buttons` grid `gap: 10px`) on all four category backgrounds (number/operator/clear/equals).

**Expected Result:** Each focused button shows `outline: 2px solid #ffffff` (rgb(255,255,255)) with `outline-offset: 2px`, fully visible against its own background color (#3A3A3A, #D9822B, #C0392B, #6C4BD1) and not clipped by the 10px grid gap, per `:focus-visible` rule in `src/App.css` and requirement R4.
