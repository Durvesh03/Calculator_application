## 2. Dependencies and Sequencing (summary)

```
T-1 (tokens)
  ├─> T-2 (.number)   ──┐
  ├─> T-3 (.operator) ──┤
  ├─> T-4 (.clear)    ──┤──> T-6 (:focus-visible)
  └─> T-5 (.equals)   ──┘
T-2 ──> T-7 (JSX: number classNames) ──> T-8 (JSX: zero + number)
T-3 ──> T-9 (JSX: operator classNames)
T-6, T-7, T-8, T-9 ──> T-10 (manual AC-1–AC-7 check)
T-6, T-10 ──> T-11 (manual focus-clipping check, R4)
```
Rationale: the token block (T-1) must exist before any category rule references it (CSS custom properties must be defined before use for the intended cascade, and for reviewer clarity). The four category rules (T-2–T-5) are independent of each other and may be done in any order or a single pass, but all precede the shared `:focus-visible` rule (T-6) so the outline can be reviewed against all four finished backgrounds at once. The `src/App.jsx` className additions (T-7–T-9) are independent of each other but each depends on its corresponding CSS category rule already existing, so that a reviewer/tester sees the intended color the moment the class is added rather than an unstyled intermediate state. Both manual checks (T-10, T-11) run only after all code tasks are complete.
